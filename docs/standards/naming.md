# การตั้งชื่อ

> **ชื่อยาวได้ถ้ามันเจาะจง · ชื่อสั้นที่กว้างคือชื่อที่แย่กว่า**
> (ผู้ใช้สั่งไว้ 2026-08-26 — `Session` ถูกเปลี่ยนเป็น `UserSession` ด้วยเหตุผลนี้)

ชื่อที่ดีตอบได้ว่า "ของนี้คืออะไร" โดยไม่ต้องเปิดไฟล์ไปอ่าน
ชื่อที่กว้างประหยัดตัวอักษรวันนี้ แล้วเก็บดอกเบี้ยทุกครั้งที่มีคนต้องเดา

---

## ข้อเดียวที่ต้องจำ

**ถามว่า "ชื่อนี้ใช้กับของอื่นในระบบได้อีกกี่อย่าง"** — ตอบได้มากกว่าศูนย์ แปลว่ายังกว้างไป

| กว้างไป | เจาะจง | ทำไม |
|---|---|---|
| `Session` | `UserSession` · `PetOwnerSession` | เซสชันของอะไร · ระบบนี้มี session สองชนิด |
| `Log` | `LoginLog` · `AuditLog` | log ของอะไร |
| `Status` | `WorkStatus` · `VisitStatus` | สถานะของอะไร |
| `Item` | `VisitItem` | รายการของอะไร |
| `data` · `result` · `temp` | `activeBranches` · `ownedPets` | ตัวแปรที่ไม่บอกว่าข้างในคืออะไร |
| `handle()` · `process()` | `revokeSessionsOfRole()` | ทำอะไรกับอะไร |

**ยาวเกินไปคือยาวโดยไม่เพิ่มความชัด** ไม่ใช่ยาวเพราะหลายคำ —
`UserSessionTokenHashValue` ยาวเปล่า เพราะ `tokenHash` ก็เจาะจงพออยู่แล้วในบริบทของ `UserSession`

---

## ตัวเรือน

| ของ | รูป | ตัวอย่าง |
|---|---|---|
| Prisma model | `PascalCase` เอกพจน์ | `UserSession` · `PetOwnerAccount` |
| ตาราง (`@@map`) | `snake_case` เอกพจน์ | `user_session` · `pet_owner_account` |
| คอลัมน์ | Prisma `camelCase` + `@map("snake_case")` | `tokenHash` → `token_hash` |
| enum | `PascalCase` · ค่าเป็น `SCREAMING_SNAKE` | `WorkStatus` · `ACTIVE` `TERMINATED` |
| ตัวแปร · ฟังก์ชัน | `camelCase` | `activeBranches` · `revokeSessionsOfRole` |
| type · interface | `PascalCase` | `AuthUser` |
| ค่าคงที่ระดับโมดูล | `SCREAMING_SNAKE` | `SESSION_TTL_HOURS` |
| ไฟล์ | `kebab-case` | `user-session.service.ts` |
| permission key | `<ส่วน>:<เมนู>:<read\|write>` | `main:master:read` · `main:hr:write` |

**เอกพจน์เสมอสำหรับ model และตาราง** — `user_session` ไม่ใช่ `user_sessions`
แถวหนึ่งแถวคือเซสชันหนึ่งอัน ชื่อตารางบอกว่าแถวคืออะไร ไม่ได้บอกว่ามีกี่แถว
ส่วน relation ฝั่ง to-many เป็นพหูพจน์ (`sessions UserSession[]`) เพราะมันคือหลายอันจริง ๆ

## ฟังก์ชัน — ขึ้นต้นด้วยกริยาที่บอกผลลัพธ์

| รูป | ใช้เมื่อ |
|---|---|
| `get*` / `find*` | อ่าน · `find*` คืน null ได้ `get*` ไม่คืน |
| `list*` | คืนหลายแถว |
| `create*` · `update*` · `delete*` | เขียน |
| `is*` · `has*` · `can*` | คืน boolean |
| `assert*` · `require*` | ผิดแล้ว throw |
| `to*` · `serialize*` | แปลงรูป |

**ชื่อต้องบอกด้วยว่าทำกับอะไร** — `revokeSessionsOfRole(roleId)` ไม่ใช่ `revoke(id)`
`id` ของอะไรก็ได้ อ่านที่ call site แล้วไม่รู้ว่ากำลังเพิกถอนอะไรอยู่

---

## boolean — ชื่อต้องตอบคำถามที่มีคำตอบว่าใช่หรือไม่ใช่

`mustChangePassword` · `isSystem` · `hasActiveSession`
ไม่ใช่ `passwordFlag` · `status` · `check`

**หลีกเลี่ยงชื่อปฏิเสธ** — `isNotActive` อ่านคู่กับ `!` แล้วกลายเป็นสองชั้นซ้อน

---

## เวลาและคนทำ — คู่ที่ต้องมาด้วยกัน

`<กริยาช่องสาม>At` + `<กริยาช่องสาม>By` เสมอ

`createdAt`/`createdBy` · `deletedAt`/`deletedBy` · `suspendedAt`/`suspendedBy`

**มีตัวเดียวไม่ได้** — เวลาที่ไม่รู้ว่าใครทำ กับคนที่ไม่รู้ว่าทำเมื่อไหร่ ตอบคำถามไม่ได้ทั้งคู่
ที่ `sql/parts/*.sql` มี CHECK บังคับให้ทั้งคู่ว่างหรือมีค่าพร้อมกัน

---

## ชื่อที่ผิดแล้วเจ็บเป็นพิเศษ

**`ownerId` ≠ `createdBy`** — คนคีย์อาจไม่ใช่เจ้าของ · ตั้งชื่อสลับเมื่อไหร่ รายงาน
"สัตว์ของฉัน" จะคืนแถวที่คนอื่นเป็นเจ้าของ

**คอลัมน์ที่เก็บ hash ต้องมีคำว่า `Hash` ในชื่อ** — `passwordHash` · `tokenHash`
ชื่อ `password` เฉย ๆ คือคำเชิญให้มีคนเขียนรหัสดิบลงไปสักวัน

**`null` แปลว่าอะไร ต้องเขียนไว้ที่ `///`** — `departmentId = null` เคยถูกเขียนว่า
"ใช้ได้ทุกแผนก" ทั้งที่โค้ดทำว่า "ไม่สังกัดแผนกใด" · ชื่อเดียวกัน ความหมายคนละเรื่อง

**`petOwnerAccount` ≠ `petOwner`** — ตัวแรกคือ "วิธีล็อกอิน" ตัวหลังคือ "คนที่คลินิกรู้จัก"
ชื่อที่ตัดคำว่า `Account` ทิ้ง คือชื่อที่ทำให้สองเรื่องนี้กลายเป็นเรื่องเดียวกันในหัวคนอ่าน
รายละเอียดอยู่ที่ `auth.md`

## ชื่อเทส — คนที่อ่านคือคนที่ไม่ได้เขียนโค้ด

ชื่อเทสไปโผล่ใน terminal และในรายงาน CI **เป็นไทยทั้งหมด** และต้องอ่านรู้เรื่อง
โดยไม่ต้องเปิดไฟล์ตาม

| | |
|---|---|
| `describe` | **งานที่ทำ ไม่ใช่ชื่อฟังก์ชัน** — `ชนิดสัตว์ · ดูรายการ` ไม่ใช่ `listPetSpecies` |
| `test` | ประโยคที่บอกว่าอะไรต้องเป็นจริง — `ไม่คืนแถวที่ถูก soft delete` |

อ่านรวมกันแล้วต้องได้ประโยค: `ชนิดสัตว์ · ดูรายการ › ไม่คืนแถวที่ถูก soft delete`

**ชื่อฟังก์ชันไม่ต้องอยู่ในชื่อเทส** — คนที่ต้องการรู้ว่าเทสตัวไหนคุมโค้ดตัวไหน
เปิดไฟล์เอาได้ · คนที่อ่านรายงานเปิดไม่ได้

---

## ภาษา

**โค้ด · ชื่อ · commit message เป็นอังกฤษ** · **คำอธิบายใน `///` ชื่อเทส และเอกสารเป็นไทย**

ชื่อไทยของตารางอยู่ใน `COMMENT ON TABLE` ที่ `sql/parts/*.sql` — ระบบอ่านกลับมาใช้
ตอนสร้างข้อความปฏิเสธ ให้ผู้ใช้เห็นคำที่ตัวเองใช้เรียก ไม่ใช่ชื่อตาราง
