## ลำดับของงาน

งานหนึ่งเรื่องเดินสี่ขั้น **ขั้นละหนึ่งใบสั่ง** ไม่ข้ามขั้น ไม่ควบขั้น

| ขั้น | สกิล | แตะอะไร |
|---|---|---|
| 1 | `schema` | `apps/api/prisma/` — ตารางกับ patch.sql |
| 2 | `service` | `apps/api/src/modules/<โมดูล>/*.service.ts` — กฎธุรกิจอยู่ชั้นนี้ที่เดียว |
| 3 | `api` | `apps/api/src/modules/<โมดูล>/*.routes.ts` — แปลง HTTP เป็นการเรียก service |
| 4 | `web` | `apps/web/src/` — หน้าจอ |

ขั้นก่อนหน้ายังไม่เสร็จ แปลว่าขั้นนี้ยังเริ่มไม่ได้ · เจอตอนไหนให้บอกแล้วรอ
ไม่ใช่แอบทำส่วนที่ขาดพ่วงไปด้วย

## กฎที่ข้ามทุกขั้น

**โค้ด · ชื่อ · commit เป็นอังกฤษ · คอมเมนต์ · ชื่อเทส · เอกสารเป็นไทย**

**เทสแดงก่อนเสมอ** — เขียนโค้ดก่อนแล้วค่อยเขียนเทสตาม คือเทสที่พิสูจน์ว่า
โค้ดทำในสิ่งที่มันทำ ไม่ได้พิสูจน์ว่ามันทำในสิ่งที่ควรทำ

**assert `code` ไม่ใช่ข้อความ** — ข้อความเปลี่ยนได้ รหัสไม่เปลี่ยน

**รันเฉพาะเทสของไฟล์ที่ตัวเองแตะ** ชุดเต็มรันเมื่อผู้ใช้สั่งด้วยคำพูด
